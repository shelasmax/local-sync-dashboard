Действия

Без delete в target
MVP-поведение запуска

Приложение стартует однонаправленный `rclone copy` без destructive действий в target. Если длинный cloud run прервётся, recovery пойдёт через повторный `copy` с дельты.

Открыть Ops / Runbook
Практический порядок
  • Если маршрут новый или большой, сначала сделайте `Dry-run`.
  • Если всё выглядит нормально, запускайте реальный `copy` из этого экрана.
  • Если run прервётся, вернитесь в `/runs` и повторите задачу с дельты.

Если сомневаетесь в маршруте или размере выгрузки, безопаснее сначала сделать `Dry-run` и короткий тест на подпапке.
