## English

**Recovery & process resilience**

Recover more clearly when a transfer process exits or a network mount disappears.

### Highlights

- A reaper runs every 5 minutes and marks `running` rows without an active owner thread as `interrupted`, cleaning stale runtime snapshots.
- Process shutdown sends SIGTERM, waits a 5-second grace period, and attempts SIGKILL if rclone has not exited.
- Unexpected execution exceptions now mark the run as failed instead of leaving it running indefinitely.
- Stream reads handle closed descriptors and I/O errors; selector cleanup runs in a finally block.

### Operator note

Check network mounts and Mac sleep settings before retrying a failed NAS route. Recovery uses a new delta copy, not reattachment.

## Русский

**Восстановление и устойчивость**

Сбои процесса переноса и отключение сетевой папки получают более понятное завершение.

### Что изменилось

- Проверка каждые 5 минут помечает `running` без активного потока как `interrupted` и очищает устаревшие runtime snapshots.
- При остановке отправляется SIGTERM, затем после 5 секунд ожидания — SIGKILL, если rclone не завершился.
- Неожиданные исключения выполнения теперь помечают запуск как ошибочный вместо бесконечного статуса running.
- Чтение потоков обрабатывает закрытые дескрипторы и ошибки ввода-вывода; selector очищается в finally.

### Для эксплуатации

Перед повтором NAS-маршрута проверьте сетевой том и настройки сна Mac. Восстановление выполняется новым копированием дельты, без подключения к старому процессу.
