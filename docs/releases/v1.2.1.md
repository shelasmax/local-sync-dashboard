## English

**Run archive & focused operations**

Keep current work visible while full history lives in its own archive.

### Highlights

- Split `/runs` for active work, recovery, and incidents from `/runs/archive` for full history with pagination and filters.
- Added single-run deletion and bulk archive cleanup for local history rows and log files only; source and destination data are not touched.
- Registered the archive route before the run-detail route so `archive` is not parsed as an integer run ID.
- Compacted recovery blocks with persistent Show / Hide controls and restored active-run visibility from live snapshots.

### Operator note

Archive cleanup permanently removes the selected local history and logs. Save any diagnostic evidence you need before using it.

## Русский

**Архив запусков**

Текущая работа остаётся на виду, а полная история получает отдельный архив.

### Что изменилось

- Экран `/runs` для активной работы, recovery и инцидентов отделён от `/runs/archive` с полной историей, пагинацией и фильтрами.
- Добавлены удаление отдельного запуска и массовая очистка локальных записей и логов; данные источника и назначения не затрагиваются.
- Маршрут архива зарегистрирован раньше страницы запуска, чтобы `archive` не разбирался как числовой ID.
- Recovery-блоки стали компактнее и получили «Скрыть / Показать»; активные запуски снова отображаются по живым snapshots.

### Для эксплуатации

Очистка архива безвозвратно удаляет выбранную локальную историю и логи. Сохраните нужную диагностическую информацию заранее.
