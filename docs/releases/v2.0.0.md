## English

**Reliable macOS service mode**

Run the dashboard as a managed local service outside Documents.

### Highlights

- Documented a service copy under `~/Library/Application Support/com.localsync.dashboard/service` to avoid background access failures in privacy-protected folders.
- Added `scripts/update_launchd_service.sh` to refresh service code and its virtualenv, preserve `service/var`, and restart the LaunchAgent.
- Added `scripts/launchd_status.sh` to inspect agent state, PID, the listener, HTTP readiness, and service logs.
- Standardized manual and service operation on `127.0.0.1:8000`.

### Operator note

The updater restarts the service: finish active transfers first. Initial setup does not migrate repository `var/` automatically. See the current operations guide for installation, backup, and rollback.

## Русский

**Service-mode на macOS**

Запускайте панель как управляемый локальный сервис вне Documents.

### Что изменилось

- Описана service-копия в `~/Library/Application Support/com.localsync.dashboard/service`, чтобы избежать отказов фонового доступа к защищённым папкам macOS.
- Добавлен `scripts/update_launchd_service.sh`: обновление кода и virtualenv сервиса, сохранение `service/var`, перезапуск LaunchAgent.
- Добавлен `scripts/launchd_status.sh` для проверки агента, PID, порта, HTTP-доступности и логов сервиса.
- Адрес `127.0.0.1:8000` закреплён как стандарт ручного запуска и service-mode.

### Для эксплуатации

Скрипт обновления перезапускает сервис: сначала завершите активные переносы. При первой установке `var/` репозитория автоматически не мигрирует. Установка, backup и откат описаны в актуальном руководстве.
