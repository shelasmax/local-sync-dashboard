## English

**Diagnostics that lead to action**

Turn profile problems into clear next steps, and keep operational screens stable.

### Highlights

- Profile counters and contextual help link directly to Ops scenarios for remotes, authentication, permissions, paths, and Synology mounts.
- Active, recovery, and incident sections on `/runs` retain explicit empty states when no live snapshot exists.
- Fixed persistent Show / Hide controls across the overview, jobs, and runs pages.
- Interrupted runs appear alongside failed and blocked incidents; setup diagnostics failures no longer make `/profiles` return HTTP 500.

### Operator note

Use the diagnostic action on a profile to open its relevant runbook scenario.

## Русский

**Диагностика и исправления**

Проблемы профилей ведут к понятным действиям, а рабочие экраны остаются устойчивыми.

### Что изменилось

- Счётчики и подсказки профилей ведут к сценариям Ops для remotes, авторизации, прав доступа, путей и томов Synology.
- Секции активных запусков, recovery и инцидентов на `/runs` показывают явные пустые состояния при отсутствии живого snapshot.
- Исправлены переключатели «Скрыть / Показать» с сохранением состояния на главной, в задачах и запусках.
- Прерванные запуски показываются рядом с ошибками и блокировками; сбои setup-диагностики больше не приводят к HTTP 500 на `/profiles`.

### Для эксплуатации

Откройте действие в диагностике профиля, чтобы перейти к подходящему сценарию runbook.
